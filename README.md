# Heart-Disease-Prediction
 Created Linear Regression model in Java using the Framingham Dataset, training on health related factors located within the dataset to predict heart disease currently at a 62%  accuracy. These features include male,age,education,currentSmoker,cigsPerDay,BPMeds,prevalentStroke,prevalentHyp,diabetes,totChol,sysBP,diaBP,BMI,heartRate,glucose,TenYearCHD
